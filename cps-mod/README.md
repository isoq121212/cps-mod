# CPS Mod для BedWars 🎮
**Minecraft 1.16.5 | Fabric**

Показывает КПС (клики в секунду) прямо на экране — отдельно для левой и правой кнопки мыши.

## Как выглядит
В левом нижнем углу экрана отображается:
```
LMB: 12 CPS   ← левая кнопка (зелёный)
RMB: 4 CPS    ← правая кнопка (красный)
```

### Цвета КПС:
- 🟢 **10+** — зелёный (отличный КПС)
- 🟡 **6–9** — жёлтый (средний)
- 🔴 **0–5** — красный (низкий)

## Как собрать мод

### Требования:
- **JDK 8** (Java 8)
- **Gradle** (или используй gradlew)

### Шаги:
1. Скачай [Fabric Example Mod](https://github.com/FabricMC/fabric-example-mod) как основу для структуры проекта (нужны gradlew файлы)
2. Скопируй файлы из этого мода в нужные папки
3. Открой терминал в папке проекта и выполни:
   ```bash
   ./gradlew build
   ```
4. Готовый `.jar` файл появится в папке `build/libs/`

### Установка:
1. Установи [Fabric Loader 1.16.5](https://fabricmc.net/use/)
2. Скачай [Fabric API 0.40.8+1.16](https://modrinth.com/mod/fabric-api)
3. Положи оба `.jar` файла в папку `mods/`
4. Запусти Minecraft!

---

## Как работает
- `CpsTracker` отслеживает нажатия кнопок мыши каждый тик
- Клики хранятся в очереди с временными метками
- Клики старше 1 секунды автоматически удаляются
- `CpsHudRenderer` каждый кадр рисует текущее количество кликов в очереди
